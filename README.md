Sistema de coleta e gerenciamento de feedbacks com suporte web e mobile.

### Projeto Init
https://github.com/Nymeds/ProjetoInit

Plataforma de dashboard para grupos com atividades, chat em tempo real e integração com IA.

Stack: React, Node.js (Fastify), Prisma, Zod, Vitest, Vite, React Native

Funcionalidades:
- Autenticação com JWT em cookies
- Chat em tempo real (WebSockets)
- Integração com IA (Gemini)
- Recuperação de senha com NodeMailer
